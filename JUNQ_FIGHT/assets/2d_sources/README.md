# Public 2D reference packs

- `streets_of_fight_files.zip` — Streets of Fight by ansimuz; CC0 on OpenGameArt. Source page: https://opengameart.org/content/streets-of-fight. The archive's `public-license.txt` is preserved in the extracted source directory and the project-used urban stage folder.
- `DojoJim.zip` — Dojo Jim by awesomeduck; CC0. Source page: https://opengameart.org/content/dojo-jim. Reviewed as an alternative; its tiny 64×64 RPG-style character is not used in the playable scene.

Godot ignores this folder. Runtime copies are under `assets/characters/2d/street_fight/` and `assets/stages/2d/urban/`.
